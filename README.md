# Chess Puzzles Analysis

This repository contains an analysis of chess puzzles generated by different engines and configurations. The goal is to compare puzzle quality, difficulty, and thematic distribution across multiple approaches, including classical algorithms and neural-based systems.

## 📁 Repository Structure

```
.
├── Imagens/        # Generated plots and visualizations
├── Puzzles/        # CSV datasets with generated puzzles
├── Scripts/        # Python scripts for analysis and plotting
```

### 📊 Imagens/

Contains visual results of the analysis, such as:

* Bar charts comparing engines
* Pie charts of puzzle themes
* Performance comparisons across depths and methods

### ♟️ Puzzles/

Datasets of generated chess puzzles in CSV format. These include:

* DeepChess vs ComputerChess comparisons
* DeepChess vs Lichess puzzles
* Minimax (classical) variations with different depths
* Baseline engine datasets

### 🧠 Scripts/

Python scripts used for processing and visualization:

* `count_ratings.py` – Analyze rating distributions
* `count_themes.py` – Extract and count puzzle themes
* `graph_bar.py` – Generate bar charts
* `graph_pie.py` – Generate pie charts
* `graph_epoch.py` – Analyze performance over iterations
* `graphs.py` – General plotting utilities

## 🚀 Objectives

* Compare different chess engines in puzzle generation
* Evaluate puzzle difficulty and distribution
* Analyze thematic diversity (e.g., forks, pins, mates)
* Study the impact of search depth on puzzle quality

## ⚙️ Requirements

* Python 3.x
* Recommended libraries:

  * `pandas`
  * `matplotlib`
  * `numpy`

Install dependencies with:

```bash
pip install pandas matplotlib numpy
```

## ▶️ Usage

Run the scripts from the `Scripts/` directory. Example:

```bash
python Scripts/count_ratings.py
python Scripts/graph_bar.py
```

Make sure the dataset paths inside the scripts match your local setup.

## 📈 Results

The repository includes several visual comparisons between:

* Deep learning-based approaches (e.g., DeepChess)
* Classical search algorithms (Minimax)
* External datasets (e.g., Lichess)

These results help highlight differences in puzzle quality and characteristics.

## 📌 Notes
